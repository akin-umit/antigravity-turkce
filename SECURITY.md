# Güvenlik

Güvenlik açığı, bozuk yama veya şüpheli bir dağıtım tespit ederseniz public issue içinde kişisel veri veya hassas dosya paylaşmayın.

Resmî ikili dosyalar yalnızca bu GitHub deposunun **Releases** bölümünden veya README'de açıkça belirtilen resmi indirme bağlantısından yayımlanır.

Manager güncellemeleri SHA-256 doğrulamasını destekler. Kod imzalama sertifikası eklendiğinde Authenticode doğrulaması da yayın zincirine dahil edilecektir.

## Güvenli bildirim

- Hassas bilgi içermeyen hatalar için GitHub Issues kullanılabilir.
- Kişisel veri, erişim anahtarı, proje dosyası veya özel log paylaşmayın.
- Bir dağıtım dosyasının resmi olup olmadığından emin değilseniz önce bu depodaki duyuruları ve checksum bilgisini kontrol edin.
