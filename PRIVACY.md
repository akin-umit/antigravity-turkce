# Gizlilik

Antigravity Türkçe Manager:

- Telemetri veya kullanım analitiği toplamaz.
- Kullanıcı konuşmalarını herhangi bir sunucuya göndermez.
- Proje kaynak kodunu veya terminal içeriğini dışarı aktarmayı amaçlamaz.
- Yerel olarak Antigravity kurulum yolunu, `app.asar` dosyasını, yedekleri ve Manager durum/log dosyalarını işler.
- Güncelleme kontrolü sırasında `api.github.com` ve GitHub Release indirme adresleriyle bağlantı kurar.

Yerel durum ve log klasörü:

`%LOCALAPPDATA%\AntigravityTurkce`

Antigravity yedekleri:

`%LOCALAPPDATA%\Programs\antigravity\resources\TR_BACKUP`
