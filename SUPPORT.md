# Destek

## Hata / çeviri bildirimi

GitHub **Issues** bölümünde hazır formları kullanabilirsiniz:

- **Hata bildirimi** — Manager, yama, güncelleme, otomatik koruma veya geri yükleme sorunları.
- **Çeviri eksik / hatalı** — İngilizce kalan veya daha iyi çevrilebilecek arayüz metinleri.

Lütfen issue içine parola, API anahtarı, kişisel veri, özel proje kodu veya hassas log eklemeyin.
